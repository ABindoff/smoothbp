Hierarchical change-points: random slopes and change-point locations

Why random change-points?

Hierarchical piecewise models are common in longitudinal and clinical data: a treatment effect kicks in, a developmental milestone occurs, a patient transitions between disease states. The timing of that transition — the change-point \(\omega\) — often varies meaningfully between subjects. Fitting a single population change-point ignores this variation, inflates residual variance, and gives biased estimates of slope change.

The standard Bayesian solution is a hierarchical prior:

\[ \omega_j = \bar\omega + u_j, \quad u_j \sim \mathcal{N}(0, \sigma_{\mathrm{re}}^2) \]

This introduces a well-known sampling difficulty: the funnel geometry of \((\sigma_{\mathrm{re}}, u_j)\) space. When \(\sigma_{\mathrm{re}}\) is small, the posterior concentrates in a narrow neck that HMC must traverse with a tiny step size, degrading mixing.

This vignette demonstrates three approaches to the funnel, in increasing sophistication:

Approach When to use Key argument
Centred (default) Many obs per subject, large \(\sigma_{\mathrm{re}}\) reparameterise = "none"
Full NC Any funnel regime flagged by fibr reparameterise = "omega"

Simulating heterogeneous change-points

set.seed(42)
J      <- 15L          # subjects
n_j    <- 12L          # observations per subject
N      <- J * n_j

# True parameters
omega_bar_true <- 3.0
sigma_re_true  <- 0.9   # meaningful subject variation
delta_true     <- 1.8   # slope change at changepoint
rho_true       <- 2.5   # transition sharpness
sigma_y_true   <- 0.4

# Simulate
u_omega_true <- rnorm(J, 0, sigma_re_true)
subject_id   <- rep(seq_len(J), each = n_j)
tau_vals     <- rep(seq(0.5, 5.5, length.out = n_j), times = J)

omega_i <- omega_bar_true + u_omega_true[subject_id]
d_i     <- tau_vals - omega_i
mu_i    <- delta_true * d_i * plogis(rho_true * d_i)
y_i     <- mu_i + rnorm(N, 0, sigma_y_true)

dat <- data.frame(
  subject = factor(subject_id),
  tau     = tau_vals,
  y       = y_i
)

cat(sprintf(
  "N = %d  |  J = %d  |  true sigma_re = %.2f  |  omega range [%.1f, %.1f]\n",
  N, J, sigma_re_true,
  min(omega_bar_true + u_omega_true),
  max(omega_bar_true + u_omega_true)
))
true_omega <- omega_bar_true + u_omega_true
ggplot(dat, aes(x = tau, y = y, group = subject, colour = subject)) +
  geom_line(alpha = 0.5, linewidth = 0.5) +
  geom_vline(
    data = data.frame(subject = factor(seq_len(J)), omega = true_omega),
    aes(xintercept = omega, colour = subject),
    linetype = "dashed", alpha = 0.6, linewidth = 0.4
  ) +
  scale_colour_viridis_d(guide = "none") +
  labs(title = "Simulated data — heterogeneous change-points",
       x = "tau", y = "y") +
  theme_minimal(base_size = 12)

Step 1 — Centred parameterisation (default)

We start with the default centred parameterisation. The (1 | subject) syntax in the omega formula specifies that each subject has its own change-point location, distributed around a shared population mean.

priors_used <- smoothbp_priors(
  omega       = prior_normal(3, 1.5, lb = 0),
  sigma_re_om = prior_invgamma(2, 1)
)

fit_cent <- smoothbp(
  y ~ tau,
  b0     = ~ 1 + (1 | subject),
  omega  = list(~ 1 + (1 | subject)),
  deltas = list(~ 1),
  data   = dat,
  priors = priors_used,
  chains = 4L, iter = 2000L, warmup = 1000L,
  reparameterise = "none",   # centred (default)
  seed = 42L
)
cat(sprintf("Centred  — divergences: %d\n", fit_cent$n_divergent))
s_cent <- summary(fit_cent, effects = "fixed")
re_cent <- summary(fit_cent, effects = "ran_pars")
key_vars <- c("omega1_(Intercept)", "delta1_(Intercept)", "rho1_(Intercept)", "sigma")
print(s_cent[s_cent$variable %in% key_vars,
             c("variable", "mean", "Q2.5", "Q97.5", "Rhat", "Bulk_ESS")],
      row.names = FALSE)
cat(sprintf("\nsigma_re_omega1: mean = %.3f  Rhat = %.3f  ESS = %d\n",
            re_cent$mean[re_cent$variable == "sigma_re_omega1"],
            re_cent$Rhat[re_cent$variable == "sigma_re_omega1"],
            as.integer(re_cent$Bulk_ESS[re_cent$variable == "sigma_re_omega1"])))

The centred parameterisation recovers the parameters well but can show high Rhat for omega1_(Intercept) when \(\sigma_{\mathrm{re}}\) is substantial — a textbook example of the hierarchical funnel.

Step 2 — Diagnose geometry with fibr

The fibr package (Bindoff, 2026) computes the Fisher information decomposition at each posterior draw. The key diagnostic is prior_frac: the fraction of information about each subject’s change-point that comes from the prior rather than the data.

\[ \text{prior\_frac}_j = \frac{\sigma_{\mathrm{re}}^{-2}} {\sigma_{\mathrm{re}}^{-2} + \sigma^{-2}\sum_{i \in j} \!\left(\tfrac{\partial\mu_i}{\partial\omega_{j,i}}\right)^{\!2}} \]

  • prior_frac → 1: prior dominates → funnel regime → NC recommended
  • prior_frac → 0: data dominates → centred is efficient

delta_j = sqrt(prior_frac_j) is the recommended per-group NC mixing fraction (from the Gaussian partial-NC theory of Papaspiliopoulos et al. 2007).

library(fibr)

advice <- smoothbp_advisor(fit_cent, n_draws = 200L)
print(advice)
plot(advice)

If any subjects are flagged (high prior_frac), refit with reparameterise = "omega" to apply non-centring across all omega random effects.

Step 3 — Full NC: non-centred for all groups

When all groups are in the funnel regime, apply NC uniformly. This replaces \(u_j\) with \(z_j = u_j / \sigma_{\mathrm{re}}\), where \(z_j \sim N(0,1)\) independently of \(\sigma_{\mathrm{re}}\).

fit_nc <- smoothbp(
  y ~ tau,
  b0     = ~ 1 + (1 | subject),
  omega  = list(~ 1 + (1 | subject)),
  deltas = list(~ 1),
  data   = dat,
  priors = priors_used,
  chains = 4L, iter = 2000L, warmup = 1000L,
  reparameterise = "omega",   # NC for all groups
  seed = 42L
)
cat(sprintf("Full NC  — divergences: %d\n", fit_nc$n_divergent))

Comparing mixing across parameterisations

fmt_row <- function(fit, label) {
  s  <- summary(fit, effects = "fixed")
  re <- summary(fit, effects = "ran_pars")
  om <- s[s$variable == "omega1_(Intercept)", ]
  sr <- re[re$variable == "sigma_re_omega1", ]
  data.frame(
    parameterisation = label,
    parameter        = c("omega1_(Intercept)", "sigma_re_omega1"),
    Rhat             = c(om$Rhat, sr$Rhat),
    Bulk_ESS         = c(as.integer(om$Bulk_ESS), as.integer(sr$Bulk_ESS)),
    stringsAsFactors = FALSE
  )
}

rows <- list(fmt_row(fit_cent, "Centred"),
             fmt_row(fit_nc,   "Full NC"))
comp <- do.call(rbind, rows)
comp$parameterisation <- factor(comp$parameterisation,
  levels = c("Centred", "Full NC"))

print(comp, row.names = FALSE)

Comparison with Stan (centred parameterisation)

For reference we fit the same model in Stan using the standard centred form. This illustrates how the funnel affects a general-purpose sampler without the geometry-aware Fisher metric mass matrix that smoothbp uses.

library(cmdstanr)

stan_code <- "
data {
  int<lower=0> N;
  int<lower=1> J;
  array[N] int<lower=1,upper=J> subject;
  vector[N] tau;
  vector[N] y;
}
parameters {
  real delta;
  real<lower=0> rho;
  real omega_bar;
  real<lower=0> sigma_re;
  real<lower=0> sigma_y;
  vector[J] u_omega;
}
model {
  delta     ~ normal(0, 3);
  rho       ~ normal(3, 2);
  omega_bar ~ normal(3, 1.5);
  sigma_re  ~ inv_gamma(2, 1);
  sigma_y   ~ exponential(2);
  u_omega   ~ normal(0, sigma_re);
  {
    vector[N] omega_i = omega_bar + u_omega[subject];
    vector[N] d = tau - omega_i;
    vector[N] mu = delta * d .* inv_logit(rho * d);
    y ~ normal(mu, sigma_y);
  }
}
"
stan_file <- write_stan_file(stan_code)
mod_stan  <- cmdstan_model(stan_file)

fit_stan <- mod_stan$sample(
  data    = list(N = N, J = J, subject = subject_id,
                 tau = tau_vals, y = y_i),
  chains  = 4L, parallel_chains = 4L,
  iter_warmup = 1000L, iter_sampling = 1000L,
  seed    = 42L, refresh = 0L
)

cat("Stan sampler diagnostics:\n")
fit_stan$diagnostic_summary()
draws_stan <- fit_stan$draws()

re_smoothbp <- summarise_draws(
  subset_draws(fit_nc$draws,
               variable = c("omega1_(Intercept)", "sigma_re_omega1")),
  "rhat", "ess_bulk"
)
re_stan <- summarise_draws(

cat("─── smoothbp Full NC (geometry-aware NUTS) ─────────────────────\n")

Summary

Two independent sources of sampling difficulty arise in random-omega models, and smoothbp addresses each separately:

Problem Cause Solution
Within-subject slope–changepoint coupling Off-diagonal Fisher metric between \(u_\omega\), \(u_\delta\), \(u_{b1}\) Joint per-subject NUTS with analytic mass matrix (joint_subject_nuts)
Hyperparameter funnel \((\sigma_{\mathrm{re}}, u_j)\) geometry as \(\sigma_{\mathrm{re}} \to 0\) NC flagged by fibr prior_frac diagnostic

Two parameterisation choices:

Parameterisation Syntax Best for
Centred reparameterise = "none" Data-rich regimes (many obs per subject)
Full NC reparameterise = "omega" Any funnel regime; use fibr to diagnose

The recommended workflow: fit centred, diagnose with fibr::smoothbp_advisor(), and if any groups are flagged, refit with reparameterise = "omega".
